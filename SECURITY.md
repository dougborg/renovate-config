# Security policy

## Supported versions

This repository publishes no releases: Renovate reads the presets from `main`, so only `main` receives fixes.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/dougborg/renovate-config/security/advisories/new), not in a public issue.
Include the affected preset, a description of the problem, and steps to reproduce it.
You should get an acknowledgement within a week.
Fixes land on `main`, and the advisory is published once the fix is merged.
